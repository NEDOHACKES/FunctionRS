# FunctionRS — Auto Miner for Horizon

Native Rust auto-miner for Horizon Minecraft 26.3 single-player worlds.

Features:
- Insert opens/closes the Auto Miner control menu.
- Change Block workflow: capture Start and End while standing on the selected blocks.
- Layer-by-layer route planning.
- Four mining footprints: 1x1, 3x1, 3x2, 3x3.
- Movement modes: Walk, Mixed, Sprint, Sprint + Jump.
- Uses Horizon's normal player block-breaking path.

The native source is pinned to one Horizon revision in compatibility.json.

Full Horizon compilation requires a local Horizon checkout and prepared Minecraft resources.
